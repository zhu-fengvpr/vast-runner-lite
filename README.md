# vast-runner-lite



拿来练手的小仓库

## 用法

```bash
cat data.txt | ./run.sh
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/vast-runner-lite.git
cd vast-runner-lite
chmod +x run.sh
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。
